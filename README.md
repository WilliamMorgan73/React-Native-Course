# Notes App (Tutorial Project)

This project follows along with [Traversy Media's Notes App tutorial on YouTube](https://www.youtube.com/watch?v=bCpFbERgj7s).  
It uses [Appwrite](https://appwrite.io/) as the backend for authentication and database management.  

## Tutorial Resources
- 📺 [YouTube Video](https://www.youtube.com/watch?v=bCpFbERgj7s)  
- 💻 [Original GitHub Repo](https://github.com/bradtraversy/notes-appwrite)  

## Tech Stack
- **React** (frontend)
- **Appwrite** (backend as a service)

## Features
- User authentication with Appwrite
- Create, read, update, and delete notes
